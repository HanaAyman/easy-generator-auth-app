# Frontend

React + TypeScript SPA (Vite, react-router, react-hook-form, zod). See the root
[README](../README.md) for the full setup and architecture overview.

```bash
npm install
cp .env.example .env
npm run dev        # http://localhost:5173
npm run lint        # oxlint
npm test            # Vitest + React Testing Library
npm run build       # production build to dist/
```
